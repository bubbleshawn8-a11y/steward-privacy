# Steward — Privacy

Steward is a personal, single-user tool. It is used only by its developer.

- It requests access to Google Calendar events (calendar.events scope) of the developer's own account.
- Calendar data is stored only on the developer's own computer/server and is never sold, shared or published.
- No data is sent to third parties other than the services the developer configures (Telegram, an AI model API) and only for the developer's own use.
- Access can be revoked at any time at https://myaccount.google.com/permissions.
